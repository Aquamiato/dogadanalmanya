# Doğadan Almanya

Bu depo, Türkiye'den Almanya'ya doğal bal çeşitleri, petek bal, kuruyemiş ve lokum satışı için basit iki dilli (Türkçe ve Almanca) statik bir web sitesi içerir.

Dosyalar:
- index.html — Ana sayfa ve iki dilli içerik
- styles.css — Basit stiller

Hızlı başlama:
1. Repo'yu GitHub Pages ile yayınlamak için: Repository > Settings > Pages bölümünden `main` branch ve `/ (root)` seçeneğini etkinleştirin.
2. İletişim bilgilerini (e-posta, telefon) index.html içinde güncelleyin.
3. Ürün görselleri eklemek için `images/` klasörü oluşturup index.html'de ilgili <img> etiketlerini ekleyin.

Geliştirme önerileri:
- Gerçek ürün verilerini JSON veya Markdown dosyalarında tutarak sayfayı dinamik hale getirebilirsiniz.
- Sipariş formu/ödeme entegrasyonu gerekiyorsa basit bir form backend'i veya e-ticaret çözümü (Shopify, WooCommerce, vs.) ekleyin.
- Çok dilli yönetimi genişletmek için i18n yaklaşımı veya statik site jeneratörleri (Hugo, Jekyll, Eleventy) kullanın.

Notlar:
- Mevcut içerik örnek amaçlıdır. Fiyatlandırma, stok ve gümrükleme bilgileri için doğrudan iletişime geçin.
